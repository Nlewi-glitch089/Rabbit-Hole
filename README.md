# Rabbit Hole

Rabbit Hole is a concept for an interactive curiosity and discovery app. The idea is to give people a place to follow the things that make them curious and see where those questions lead.

This repository currently contains the original clickable wireframe for the project. It was created to explore the layout, visual direction, navigation, and core experience before building the full application.

## Wireframe

The wireframe is built with:

- HTML
- CSS
- JavaScript

It does not use a framework, build tool, or backend.

### Files

- `wireframe.html` — The screens and content for the prototype
- `wireframe.css` — Visual styling, responsive layouts, and animations
- `wireframe.js` — Screen navigation and prototype interactions

The wireframe includes the main Rabbit Hole experience, including creating a rabbit hole, exploring discoveries, viewing collections, and tracking exploration progress.

## Next Steps

The wireframe will serve as the foundation for the full Rabbit Hole application, where the exploration experience and user data can be developed further.
